江苏电子信息职业学院 · 720° 校园全景（静态网站版）
========================================================

【上传部署】

index.html 是网站主入口。
已生成的 dist 文件夹可直接上传到 Netlify 的手动部署区域。
也可先解压 netlify-deploy.zip，再上传解压后的文件夹。
请确认上传文件夹的第一层有 index.html、images、thumbs 和 viewer。
线上访问使用站点根地址，访客无需安装 Python 或 Node.js。

修改文件后，在项目根目录运行：
    python build/package_site.py
即可刷新 dist 和部署压缩包。

完整部署与更新步骤见 README.md。

【本地怎么打开】

1. 双击本文件夹里的 “启动.bat”
2. 稍等 1～2 秒，浏览器会自动打开：
   http://127.0.0.1:8000/
3. 看完后，关闭那个黑色命令行窗口即可停止本地服务。

注意：不要直接双击 index.html。
浏览器的本地文件安全策略（file://）会阻止 WebGL 读取全景图，
表现为黑屏或 “全景加载失败”。请务必用 “启动.bat” 打开。

【电脑需要什么】

本工具需要一个本地静态服务器，二选一即可：

- Python 3（推荐）
  下载：https://www.python.org/downloads/
  安装时勾选 “Add Python to PATH”。

- Node.js
  下载：https://nodejs.org/
  如果电脑里没有 Python，但有 Node.js，“启动.bat” 会自动改用
  自带的 server.js 启动服务。

如果两个都没有，双击后会提示安装。

【端口被占用怎么办】

默认使用 8000 端口。如果打开后提示端口被占用，或者页面不是本全景：

用记事本打开 “启动.bat”，把
    set "PORT=8000"
改成
    set "PORT=8010"
保存后再双击运行，浏览器地址会变成：
   http://127.0.0.1:8010/

【内容说明】

- 44 个场景，每个场景 6 张 2500×2500 立方体全景图
- 场景名称、初始视角、导航热点均按原站还原
- 场景缩略图、搜索、场景列表、相邻场景跳转
- 总大小约 170 MB，全部本地文件，断网也能看

目录结构：
  index.html         网站主入口
  tour.html          旧地址跳转页
  netlify.toml       仓库部署配置
  dist\              可直接上传的部署文件夹
  netlify-deploy.zip  部署压缩包
  tour_data.json     场景与热点数据（备份/参考）
  cover.jpg          加载页背景图
  images\            44 个场景的全景图（6 面/场景）
  thumbs\            场景缩略图
  viewer\            Pannellum 全景播放器
  server.js          Node.js 备用本地服务器
  启动.bat           一键启动脚本

【操作】

- 鼠标拖动 / 方向键：环顾四周
- 滚轮 / 双指缩放：放大、缩小
- 场景中的白色圆点：前往相邻场景（鼠标悬停会显示名称）
- 左侧场景列表 / 搜索框：跳转任意场景
- R：自动旋转
- F：全屏
- N / P：下一场景 / 上一场景
- 手机：点左上角 ☰ 打开场景列表

【常见问题】

1. 页面一直显示 “正在加载首个场景…”
   本地预览请确认是通过 “启动.bat” 打开的，而不是直接双击 HTML。
   Netlify 网站请使用站点根地址，并检查部署目录第一层包含 index.html。
   仍然不行时，换 Chrome / Edge 浏览器试试。

2. 提示 “当前浏览器不支持 WebGL”
   请更新显卡驱动，或在 Chrome 设置里开启硬件加速。

3. 画面很卡
   本版使用 2500px 高清立方体贴图，显存占用较高。
   关闭其他占用显卡的软件，或换一台带独立显卡的电脑。

4. 想分享网站
   将 dist 文件夹直接上传到 Netlify；或解压 netlify-deploy.zip 后上传解压目录。
   确保上传目录第一层包含 index.html。修改文件后运行 python build/package_site.py 刷新部署包。
   原素材说明限制公开传播；创建公开站点前，请先确认已取得相应发布许可。

   如需本地离线分享，可打包整个文件夹；对方解压后运行 “启动.bat”。
   这种方式需要对方电脑安装 Python 或 Node.js。
